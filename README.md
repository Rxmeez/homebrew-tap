# Rxmeez Tap

## How do I install these formulae?

`brew install rxmeez/tap/<formula>`

Or `brew tap rxmeez/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "rxmeez/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
